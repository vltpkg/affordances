Each guide covers one package or one surface. Start with [Next.js](/docs/guides/nextjs) if you followed the [quickstart](/docs/quickstart).

- [**Next.js**](/docs/guides/nextjs): how `@afford/next` finds your actions, routes agent requests to them, and shares your session resolver.
- [**React and WebMCP**](/docs/guides/react): `AffordProvider` turns the current page's actions into WebMCP tools for browser agents. `Affordance` marks the controls in the DOM.
- [**MCP**](/docs/guides/mcp): `@afford/mcp` turns any Afford site into two MCP tools, for Claude, Cursor, and other MCP clients.
- [**Lint**](/docs/guides/lint): two rules that keep the manifest buildable and every server-action control visible to agents.
- [**Security**](/docs/guides/security): default deny, explicit confirmation, Origin checks for cookies, and a fixed order of checks on every agent call.
- [**Bench**](/docs/guides/bench): how the benchmark compares a browser agent with an Afford agent on the same tasks.
- [**Markdown**](/docs/guides/md): `@afford/md` serves every page as Markdown, at `/page.md` and to `Accept: text/markdown`, from the page's own render.
