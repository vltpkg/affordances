Each guide covers one package or one surface. New to Affordances? Start with [Getting started](/docs/guides/nextjs/getting-started).

- [**Next.js**](/docs/guides/nextjs): set up an existing app with an agent or by hand, then how files, routing, route handlers, plugins, and sessions work.
- [**React and WebMCP**](/docs/guides/react): `AffordancesProvider` turns the current page's actions into WebMCP tools for browser agents. `Affordance` marks the controls in the DOM.
- [**MCP**](/docs/guides/mcp): `@affordances/mcp` turns any Affordances site into two MCP tools, for Claude, Cursor, and other MCP clients.
- [**Lint**](/docs/guides/lint): two rules that keep the manifest buildable and every server-action control visible to agents.
- [**Security**](/docs/guides/security): default deny, explicit confirmation, Origin checks for cookies, and a fixed order of checks on every agent call.
